# Permissions

Every permission and host in the manifest, why it is there, and the code that uses it. If a line here has no code behind it, the permission should be removed.

The manifest is generated by `wxt.config.ts`. `scripts/package-release.mjs` fails the build, and `e2e/build.spec.ts` fails the tests, if the built manifest differs from what this page describes.

## Summary

| Kind | Value | Granted | Used for |
|---|---|---|---|
| Permission | `activeTab` | when the user invokes the extension on a tab | reading the page the user asked about |
| Permission | `scripting` | at install | injecting the page reader after such an invocation |
| Permission | `storage` | at install | settings, the optional Legiit token |
| Permission | `sidePanel` | at install | the side panel |
| Permission | `contextMenus` | at install | "Analyze this page" and "Check the selected text" |
| Required host | `https://web.archive.org/*` | at install | Rewind |
| Required host | `https://lens.legiit.com/*` | at install | Legiit Command Center, only when connected |
| Content script | `https://www.google.<tld>/search*` (187 domains) | at install | reading Google results pages |
| Content script | chatgpt.com, gemini.google.com, perplexity.ai, www.perplexity.ai, copilot.microsoft.com | at install | reading AI answers |
| Optional host | `*://*/*` (http and https) | **never at install**; one named site at a time, on request | scanning pages the user chose |

Not requested, by design: `tabs`, `history`, `cookies`, `webRequest`, `debugger`, `notifications`, `offscreen`, `downloads`, `webNavigation`, `declarativeNetRequest`, `<all_urls>`. The manifest has no `web_accessible_resources` and no `externally_connectable`.

## Permissions

### `activeTab`

Lets the extension read the current tab after the user invokes it there, and only until the tab leaves that site. It replaces any standing access to "all sites".

- Granted by: the toolbar icon and the keyboard shortcut (`chrome.action.onClicked` in `src/entrypoints/background.ts`), and the two context-menu items (`chrome.contextMenus.onClicked`, same file). All three call `invoke()`.
- Used by: `probeTab()` in `src/panel/tabs.ts`, which injects the page reader. Chrome refuses the injection unless activeTab (or a site grant) is in force; the panel then shows the "Analyze this page" card (`AccessCard`, `src/ui/shared.tsx`).
- Clicks inside the side panel do not grant it. See `docs/DECISIONS.md`, row 1 and D-02/D-03.
- Tests: `e2e/access.spec.ts`.

### `scripting`

- One call: `chrome.scripting.executeScript({ target: { tabId }, files: ['/page-agent.js'] })` in `src/panel/tabs.ts` (`probeTab`).
- The injected file is `src/entrypoints/page-agent.ts`, part of the package. No code string is ever injected, and nothing is injected into the page's own JavaScript world.
- It is not used for Google or the AI sites; those have static content scripts.

### `storage`

- `chrome.storage.local`: settings (tracked brands, agency name and logo, strip and snapshot preferences, AI opt-in, selected Legiit business), the Legiit token under its own key, selector-pack overrides, and the run counter (only if gating is switched on). All in `src/storage/settings.ts`.
- `chrome.storage.session`: the last invocation (which tab, which intent), so a panel that is still opening knows what was asked. Written in `src/entrypoints/background.ts` (`invoke`), read in `src/ui/hooks.tsx`.
- `chrome.storage.local.setAccessLevel({ accessLevel: 'TRUSTED_CONTEXTS' })` closes it to content scripts (`restrictStorageToTrustedContexts`).
- `chrome.storage.sync` is not used: nothing is synced to the user's Google account.
- History, briefs and caches are in IndexedDB (`src/storage/db.ts`), which needs no permission.

### `sidePanel`

- Manifest: `side_panel.default_path = "sidepanel.html"`.
- `chrome.sidePanel.open({ windowId })` in `invoke()` (`src/entrypoints/background.ts`), inside the user's gesture.
- `chrome.sidePanel.open({ tabId })` when the user presses "Open panel" on the strip above Google results (`lens:open-panel`, same file; the button is in `src/content/strip.ts`).

### `contextMenus`

- `chrome.contextMenus.create` ×2 in `createMenus()` (`src/entrypoints/background.ts`): "Analyze this page with Legiit Lens" (pages) and "Check the selected text with New or Noise" (selections).
- `chrome.contextMenus.onClicked` in the same file calls `invoke()` with the intent (analyze the page, or check the selection).
- Why it is needed: a context-menu item is one of the few gestures that grant activeTab, it works when the toolbar icon is not pinned, and it is the only way to act on selected text in one step.

## Host access

### `https://web.archive.org/*` (required)

- Rewind reads the Wayback Machine's capture index (`/cdx/search/cdx`) and raw captures (`/web/<timestamp>id_/<url>`): `src/features/rewind/cdx.ts` builds the URLs, `src/features/rewind/load.ts` fetches them.
- Enforced in `src/net/guarded-fetch.ts`: a request with purpose `wayback` must go to this origin and must not be redirected elsewhere.
- Only when the user looks up a page's history. At most 24 captures per lookup, 2 at a time.

### `https://lens.legiit.com/*` (required)

- Used only when the user pasted a token and connected. With no token, `loadConnection()` (`src/legiit/connection.ts`) returns without making a request, and no feature calls the client.
- All calls are in `src/legiit/http-client.ts`. Reads: session, businesses, business details, Industry Pulse. Writes: only after the user confirms a dialog that shows the exact JSON (`SaveToLegiit` and `Summary` in `src/ui/shared.tsx`).
- Enforced in `src/net/guarded-fetch.ts`: purpose `legiit` must go to this origin.
- The host is an assumption until the real API exists (`docs/DECISIONS.md`, A-1).
- Tests: `e2e/legiit.spec.ts`, `e2e/network.spec.ts`.

### Google Search (content script)

- `src/entrypoints/google.content.ts`, on `https://www.<domain>/search*` for each domain in `src/config/google-domains.ts`.
- Reads the results page the user opened and adds the summary strip. Sends nothing to Google and fetches nothing.
- Why every country domain: match patterns cannot contain a wildcard TLD.

### AI sites (content script)

- `src/entrypoints/ai.content.ts`, on the hosts in `src/config/sites.ts`.
- Reads the latest answer and its cited links when the side panel asks. Never types into the page, never sends a prompt.

### Optional hosts: `*://*/*`

Listed as optional so that a specific site can be requested at run time. Nothing is granted at install, and the wildcard itself is never requested. It is one pattern rather than `https://*/*` plus `http://*/*` because Chrome only accepts a request that fits inside a single optional pattern, and a site is requested for both schemes at once (`*://*.example.com/*`). Tested in `e2e/access.spec.ts`.

- Requested in `requestAccess()` (`src/net/permissions.ts`), always as specific sites (`*://*.example.com/*`), always from a click, always after the UI named the sites and the reason (`PermissionLine`):
  - Why Not Me → "Scan sources" (`src/ui/tabs/WhyNotMeTab.tsx`)
  - New or Noise → "Compare" (`src/ui/tabs/NewOrNoiseTab.tsx`)
  - "Always allow on example.com" for the site in the current tab (`KeepAccess`)
- Checked before every fetch in `guardedFetch()` (`chrome.permissions.contains`), and again for the final address after a redirect.
- Listed and removable in Settings → Privacy and data (`grantedSites()`, `revokeSites()`).
- Tests: `e2e/network.spec.ts` ("declining Chrome's permission prompt…", "even if the panel believed…", "scans and comparisons fetch only the pages listed…").

## What reaches the network

| Destination | When | Code | Carries |
|---|---|---|---|
| web.archive.org | the user looks up a page in Rewind | `rewind/load.ts` → `guardedFetch(…, 'wayback')` | the page address being looked up |
| a site the user granted | the user starts a scan or comparison | `net/page-fetch.ts` → `guardedFetch(…, 'page')` | nothing: a plain GET without cookies or referrer |
| the site in the current tab | the user builds a brief there | `content/same-origin-fetch.ts`, inside that tab | nothing: GET without cookies |
| the Legiit API | connected, and reading account data or confirming a save | `legiit/http-client.ts` → `guardedFetch(…, 'legiit')` | the token; for saves, the JSON shown in the dialog |

Nothing else. The service worker contains no network API. The embedding model and its runtime are files in the package; the worker that runs them refuses any address outside the package. `e2e/network.spec.ts` drives every feature and fails if any other request is made.
